# Accessibility audit

Test the running experience, not markup alone. Check semantic structure, names
and labels, keyboard order, visible focus, skip/navigation behavior, contrast,
zoom/reflow, touch targets, forms/errors, dialogs/menus/tables, announcements,
screen-reader flow, reduced motion, and non-color status cues.

Prefer native semantics over unnecessary ARIA. Include automated findings only
as evidence, not proof of accessibility. Report user impact, reproduction,
standard/criterion when known, severity, and specific remediation.
