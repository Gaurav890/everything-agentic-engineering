# Design ops

Update owning artifacts with:

- approved brief, flows, states, copy, responsive and accessibility behavior;
- design-system decisions and token/component contracts;
- edge cases, agentic states, evidence, known compromises, and open decisions;
- requirement/acceptance/task traceability;
- exact implementation or review handoff.

Reference canonical artifacts instead of duplicating them. State what changed,
what remains authoritative, what was verified, and the next owner/action.
Documentation exists to reduce interpretation, not to maximize volume.
