# Benchmark

Define the user/job and comparison dimensions before selecting products.
Include direct competitors, adjacent products, and best-in-class interaction
references. Prefer current primary evidence and inspect real flows where lawful.

For each product record:

- target user and promise;
- information architecture and core journey;
- important interaction and agentic patterns;
- onboarding, empty, failure, recovery, trust, and pricing boundaries;
- strengths, weaknesses, conventions, and accessibility/performance signals.

Synthesize:

1. user expectations worth preserving;
2. patterns worth learning from;
3. failure modes to avoid;
4. unmet needs and differentiation opportunities;
5. assumptions and confidence;
6. source ledger.

Do not produce a feature-count table alone and do not recommend copying a
competitor’s visual identity.
