# User needs

For each relevant user/context, separate:

- functional need: progress the user must make;
- emotional need: how the user needs to feel;
- social need: how the user wants to be perceived or coordinate;
- underlying motivation: why the outcome matters;
- evidence, current workaround, constraint, and failure consequence.

Rewrite solution-shaped statements as outcome-oriented needs. Rank by importance
and confidence. Map proposed features to needs and flag features with no supported
need. Preserve uncertainty rather than inventing research.
