# Performance UX

Measure representative real journeys and devices. Inspect LCP, INP, CLS,
loading waterfalls, client/server boundaries, hydration, bundle/dependency
weight, fonts, images, animation cost, long tasks, and large lists.

Relate every finding to perceived experience: delayed meaning, blocked input,
layout instability, missing feedback, or battery/network cost. Recommend the
highest-impact fix and preserve visual/interaction intent. Beautiful but sluggish
is not excellent design.
