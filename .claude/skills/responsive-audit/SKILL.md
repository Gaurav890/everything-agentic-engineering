# Responsive audit

Use the running product with realistic sparse, normal, dense, long, and overflow
content. Check what stacks, collapses, scrolls, persists, becomes a drawer/sheet,
changes priority, or disappears. Verify navigation, tables, overlays, forms,
touch targets, safe areas, keyboard behavior, orientation where relevant, zoom,
and no horizontal clipping.

Capture viewport/state evidence and report defects with exact breakpoint,
content condition, expected behavior, and severity. Mobile must be intentionally
composed, not compressed desktop.
