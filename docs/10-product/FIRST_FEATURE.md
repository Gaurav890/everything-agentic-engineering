# First feature brief

In a generated web project this file contains the selected audience, promise,
and a relevant first-feature example. It is a planning aid, not approval to
implement an invented requirement.

Choose one user-visible outcome. Describe the user, useful behavior, failure
and recovery states, and how the result will be tested. Preserve approved
design choices. Review the resulting requirement and task scope before work
starts. See [the first-project guide](../60-tooling/FIRST_PROJECT.md).
