# Roadmap

Prefer outcome-based milestones over a feature dump.

## Now

- T-054: lock the Product-to-Proof category, four-activity Studio IA, supervised
  run schemas, Signalroom cross-platform journey, and benchmark protocol.
- T-055: implement the loopback-only Studio control plane over shared state.
- T-056: implement fixture-first supervised wave execution, recovery, and
  provider-neutral adapters.

## Next

- T-057: deliver the world-class governed Signalroom web/enterprise slice.
- T-058: deliver a real Expo native companion and Android/iOS evidence.
- T-059: run newcomer studies and a blind benchmark, then publish proof and a
  release only when their gates pass.

## Later

- Organization policy packs, compliance-specific evidence templates, and
  managed internal catalogs.

## Explicitly not planned

- silently connecting production services or copying credentials;
- claiming local demo adapters are production authentication or authorization;
- bulk-installing every external skill, agent, MCP, or provider;
- shipping dozens of shallow templates instead of a few complete journeys.
