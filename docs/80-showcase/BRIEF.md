# Signalroom showcase brief

## Purpose

Prove that Everything Agentic Engineering can produce a genuinely useful,
high-quality AI-native product—not only configuration and documentation.

Signalroom is an operations console for people supervising several agents doing
long-running knowledge work. It makes plans, execution state, evidence,
approvals, failures, and artifacts legible without exposing private chain of
thought or overwhelming users with raw logs.

## Primary user

An operator or product lead responsible for high-value agent work who needs to:

- understand what is running and why;
- identify the one action requiring attention;
- approve or reject consequential steps;
- interrupt or recover work safely;
- inspect evidence and resulting artifacts;
- know what changed and what remains uncertain.

## Job to be done

“When several agents are working in parallel, help me rapidly understand
progress, risk, and required decisions so I can intervene confidently without
micromanaging every tool call.”

## Success conditions

- The next required human action is visible within two seconds.
- Every run has a comprehensible plan and current state.
- Approval describes consequence, scope, evidence, and reversibility.
- Operators can pause/resume work and inspect task-specific detail.
- The interface remains usable at mobile and desktop widths.
- Empty, loading, error, and normal states are represented and testable.

## Non-goals

- A generic chatbot.
- A full agent runtime or production backend.
- Raw chain-of-thought inspection.
- A decorative dashboard with fake vanity metrics.
- Autonomous production mutations.
